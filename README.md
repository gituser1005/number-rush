# NUMBER RUSH

手札の数字と四則演算で目標値を作り、制限時間内の正解数を競うブラウザ向け数字パズルです。画面とCSSは `index.html`、ゲーム処理は `game.js` に分かれています。外部ライブラリやビルドは不要です。

## ルール

- 手札は3〜9から重複なしでランダムに4種類。ゲーム中は固定で、各数字を何度でも使えます。再挑戦時は再抽選します。
- 目標値は9〜70の整数。手札で作れる値から選び、直近6問の重複を可能な範囲で避けます。
- 使用できる演算は `+ - * /`。括弧や数字の連結は使えず、掛け算・割り算を優先します。途中結果は表示しません。
- 初期時間は60秒。正解ごとにクリア数が1増え、5秒延長します。不正解による時間減少はなく、スキップはありません。
- 進行は「数字2個の問題10問 → 以降は数字3個の問題のみ」に固定しています。問題数の設定欄はありません。数字4個の問題は出題しません。
- 「数字2・3個」は出題生成の基準です。解答の数字個数はその値に制限されず、最大25個（演算子を含め49トークン）まで入力できます。
- 最高記録はページを開いている間だけ保持し、再読み込みでリセットします。
- タイムアップ時は、最後に出題されていた問題の解答例を「式 = 目標値」の形で表示します。

## 起動方法

`index.html` をブラウザで開き、「ゲームスタート」を押します。インストールやサーバーの起動は不要です。

`index.html` と `game.js` は同じフォルダーに置いてください。タッチ操作によるダブルタップ・ピンチでの拡大縮小を抑止し、スクロールは利用できます。ブラウザやOSによる強制的なズーム設定は制御できない場合があります。

画面のボタンで数字・演算子を入力し、「判定」で解答します。「戻す」は1つ取り消し、「全消去」は式を消します。

キーボード操作は手札の数字、`+ - * /`、Enter（判定）、Backspace（1つ戻す）、Esc（全消去）に対応します。入力欄やボタンにフォーカスがある間はゲーム用ショートカットが無効です。

## GitHub Pagesへの公開

GitHubへ `main` ブランチをpushした後、リポジトリの **Settings → Pages → Build and deployment** で次のように設定します。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Save後、Pagesのデプロイ完了を待ち、表示された公開URLを開きます。ルートの `index.html` がゲームの入口です。
